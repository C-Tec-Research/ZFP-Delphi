## How the conversion works

* Each form (`.dfm`) becomes a XAML window; VCL controls map to their WPF equivalents and absolute
  positions/anchors/alignment are reproduced with Grid margins and DockPanels.
* Each unit (`.pas`) becomes a C# file; global routines and variables live in a static class named after the unit.
* Event handlers keep their Delphi signatures and are connected in `InitializeDelphiComponents()`.
* `DelphiRtl.cs` provides Delphi RTL/VCL behaviour (IntToStr, Copy, ShowMessage, Memo.Lines, TStringList, ...).
  Replace calls into it with idiomatic .NET code over time.
